# 叠卡壁纸工坊

在线体验：[打开壁纸工坊](https://xhad709.github.io/wallpaper-studio/)

在浏览器里做分层纸卡风格的手机锁屏壁纸：选配色、改文字、换字体，导出高清 PNG。

- 2 种版式：叠纸（2–5 片）和框格（2–5 格），每片、每格的位置都能调；框格可选标题放在第几格。叠纸对应上方深色块、下方文字卡片、底色留白的参考图结构
- 预设：4 套内置整套预设（晴蓝海报、克莱因四层、莫兰迪五层、晴日框格），一键套用版式、配色和字体，不改动文字；也可以把自己的设计（含文字）保存成“我的预设”，随时恢复或删除
- 14 套配色方案（克莱因蓝、勃艮第、莫兰迪、焦糖摩卡、炭灰香槟、墨绿等），与版式分开。每套包含深、中、浅色块、底色和文字颜色，按片数或格数给所有色块上色；外加随机配色
- 字体按风格分组：手写、花体连笔、斜体、无衬线、衬线、等宽，以及中文的黑体圆体、宋体仿宋、楷体书法
- “参考手写 · 导入图形”：把一张原字体无法识别的手写标题截图描成矢量，只能作为标题使用，固定显示“Positive & Confident”；另有 Grape Nuts、Mynerve、Nanum Brush Script 三款字形相近的手写字体
- 38 款字体样式：31 款来自 Google Fonts，7 款来自国内字体站的中文字体（霞鹜文楷、得意黑、江城圆体、猫啃网糖圆、云峰寒蝉体、朱雀仿宋、京华老宋体）。标题、副标题、小字可以分别设置字体
- 三段文字可分别编辑内容、字号、加粗、左右位置、字体和颜色，第二、三段支持换行
- 可以分别调节卡片表面的斜向柔光、边缘投影和圆角；已移除噪点纸纹和分割线
- 叠纸支持分别调整两处段间距、行距、标题字距、左右留白和文字上下位置；间距、卡片长度与字号独立；内容超出卡片时提示，不自动缩字
- 导出尺寸按分辨率列出对应的 iPhone 型号（iPhone X 至 iPhone 17 系列、iPhone Air、SE），另有安卓分辨率和自定义尺寸
- 预览可切换“仅壁纸 / 锁屏 / 主屏幕”：锁屏按 iOS 26 编辑界面画出日期、时间和小组件区域，小组件可放时间下方或屏幕底部，时间大小可拖动时间框右下角或用滑杆调整（有“默认”按钮）；主屏幕画出状态栏、搜索栏和 Dock 栏。这些只用于预览，不会导出
